If we apply a Defoli gate to this qubit state with the second and third qubits as control and the fourth qubit as the target, we get this state. It turns out that we can use CNOT gates to create controlled versions of single qubit gates. So we also have controlled y, z, s, t and Hadamard gates. They act the same as the CNOT, applying the gate if the control is one and does nothing if the control is zero. We represent these on a quantum circuit like this, with the regular gate box but with the line going out to the control qubit.
