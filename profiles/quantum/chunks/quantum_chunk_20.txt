When this happens, we call the vector an eigenvector of the transformation matrix that we applied, and the scalar we factored out an eigenvalue. Let's go through an example. If we have the matrix 2, 0, 1, 2 with the vector 0, 3, applying the matrix on the vector gives us the vector 0, 6. With this, we can factor out a 2, leaving us with 2 times the vector 0, 3. This gives us an eigenvalue of 2 with the eigenvector 0, 3 for that matrix. Classical computers use binary, zeros and ones, to store and process their data.
