As you can see, the function returns zero for four of the inputs and one for the other four of the inputs. For a classical computer to solve this problem, it would need to query the function in the worst case two to the power of n minus one plus one times, where n is the length of the bit string the function takes as input. This is because in the worst case, we check half of the inputs and get the same output for all of them.
