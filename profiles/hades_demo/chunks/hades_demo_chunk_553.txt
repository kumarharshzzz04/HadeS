And from a security perspective, you want to keep this as private as possible, because for some applications with just a single API key, someone can have like full access to a system, it can pull all your customer info information, it can send messages to customers, for example, if you have an API key for a CRM system. So you don't want to have that in GitHub, really, or in Git, you don't, but you just want it to be locally only where the application needs it.
