And if the root mean squared error on the validation set is like $2, but when you submit it to Kaggle, the root mean squared error is $9. Then your validation set is completely useless and you're basically shooting in the dark because you're trying to train different models to do better on the validation set, but the validation set has no relationship to the test set score. So make sure that your validation set and test sets have similar or very close scores and an increase in the score on the validation set reflects as an increase on the test set.
